# PowerShell Command Basics

My own short notes on basic PowerShell commands, the ones I use again and again in IT support practice.

It covers simple things: moving between folders, working with files, reading file contents, getting help on a command, and checking services and processes.

The basic-commands.ps1 file in this folder has small examples I can run and practice with.

I keep this simple on purpose. It is a beginner cheat sheet, not a full guide.
